# Editable experiment templates

All CSVs are UTF-8, header-only templates. Blank values mean unknown/not measured, never zero. Use project-relative file paths resolved against `/Users/airadajitauleeruk/Desktop/capstone`. Keep identifiers stable and quote text containing commas or newlines.

- [sku-registry.csv](/Users/airadajitauleeruk/Desktop/capstone/experiment/templates/sku-registry.csv): one row per approved SKU/panel reference. `sku_role` is `development_sku`, `validation_only_sku`, or `final_unseen_sku`. `panel_id` differentiates visible panels. Encode `distinguishing_fields_json` as a JSON object of verified names/grades/codes. Same-SKU rows must agree on role/family/revision policy.
- [image-manifest.csv](/Users/airadajitauleeruk/Desktop/capstone/experiment/templates/image-manifest.csv): one row per source image. IDs identify physical bags, sessions, duplicate groups, and source images. `image_split` is `development_train`, `validation`, `final_test`, or `quarantine`. Quality tags are semicolon-separated descriptive labels. Synthetic variants retain the original `source_image_id` and bag group. `true_sku_id` may be blank for no-bag images but must be verified for evaluated bag queries.
- [ocr-annotations.csv](/Users/airadajitauleeruk/Desktop/capstone/experiment/templates/ocr-annotations.csv): one row per identifying text region. `polygon_json` stores full-image pixel coordinates as `[[x,y],...]`. `field_type` identifies name/grade/code/shared brand. `readability` separates visible transcription from intended but obscured artwork text. `transcription` is blank if unavailable; do not silently insert artwork text as visible truth.
- [prediction-log.csv](/Users/airadajitauleeruk/Desktop/capstone/experiment/templates/prediction-log.csv): one row per run/query/gallery pass. `decision_state` is `recognized`, `uncertain`, `unusable_image`, or `processing_error`. `gallery_membership` is `enrolled`, `unenrolled`, or `not_applicable` and is evaluator metadata, never model input. Top-three scores refer to distinct SKUs. Text/evidence JSON fields store predictions, not labels. Timing fields use milliseconds; blank if unmeasured.
- [run-summary.csv](/Users/airadajitauleeruk/Desktop/capstone/experiment/templates/run-summary.csv): one row per run/pass/subgroup. Rate columns are decimal fractions `[0,1]`; CER can exceed `1`. `not_run` rows should leave metric fields blank. Confidence-bound fields apply to automatic identification accuracy; record the method in `interval_method`. Metrics with zero eligible denominator are blank/undefined.

Save run-specific filled copies under `experiment/runs/<run_id>/`; keep these blank templates unchanged. Model settings and provenance belong in a companion `config.json` and written run note, not in ambiguous filenames alone. These files define the data structure and do not implement a training/inference pipeline.
